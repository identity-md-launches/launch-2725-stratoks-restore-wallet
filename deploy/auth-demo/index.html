Disconnected

Connect alone does not authenticate. Sign-in asks for one readable message: no gas, transaction, private key, asset approval or transfer. A verified visit creates no resident memories or recognition.

Connect a wallet to enable sign-in.

Sessions expire after one hour and on backend restart. Credentials stay only in page memory; reloading requires sign-in again. An offline sign-out is cleared locally but requires retry to confirm server revocation. MetaMask, Rabby and compatible injected EVM providers are supported by interface; actual extensions and mobile devices have not been tested. Simulated-wallet browser tests are separate.
